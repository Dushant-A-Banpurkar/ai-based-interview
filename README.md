# AI-based-interview
This is a AI interviewer, which takes interview of person and help them to prepare.

This is a experiment project for main project AI Based Job Tracker. This Project was use has a features in the main project.

I'am developing AI Interviewer, to make an AI interviewer that takes a resume and job description from the user. Takes the interview. An interview it analysis facial expression, voice depth and body movement. The quality of the answer of the user also. I want to add sandbox features or compiler features for the assessment process during the interview. So the user feels vibes like he is giving an actual interview for the company. AI interviewers also do cross-questioning. Also, I want to add challenging questions, but optional, because we don't know if the company will ask them or not. At the end, when the interview finishes, the interview analysis data and recoding will be provided to the user. I made an AI-based resume analyzer by using Node.js, JavaScript, MongoDB, Redis, Express, OpenAI's chat completion method (currently using the OpenAI "gpt-4o-mini" model) and a REST API in the backend, and in the frontend I am using React.js, TanStack Queries and TypeScript.
